# Picture Recognition with Neural Networks

## Overview

This project explores image recognition using neural networks.

## Contents

-   `train_neural_network.ipynb` --- Jupyter Notebook containing the
    neural-network training workflow.
-   `Analysis_Project.pdf` --- project analysis and documentation.

## Tools

-   Python
-   Jupyter Notebook
-   Neural networks
-   Machine learning
-   Image recognition

## Project Focus

The project demonstrates the use of a neural network for recognizing
pictures and documents the analysis behind the project.

## How to Explore

Open `train_neural_network.ipynb` in Jupyter Notebook or another
compatible environment to review the implementation and training
process.

## Purpose

The project is part of my machine-learning portfolio and demonstrates
practical experience with neural networks and image-related
classification tasks.
